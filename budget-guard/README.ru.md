# budget-guard

<img src=".claude-plugin/icon.png" alt="" width="80" height="80" align="right">

[English](README.md) | Русский

Поддержание prompt cache и предупреждения о бюджете для Claude Code. Мод следит за
запросами основной ветки диалога, лимитами подписки и размером контекста.
Команды и уведомления сейчас на русском языке.

- Поддерживает пятиминутный prompt cache во время коротких пауз.
- Предупреждает о настраиваемых порогах лимитов 5h/7d и заполнения контекста.
- Просит повторный `Enter` перед запросом с большим холодным кэшем.
- Добавляет короткое напоминание модели о бюджете, когда расход высок.

**Keepalive делает настоящие фоновые запросы к модели и расходует лимиты.** Через
`$.model.fork` он перечитывает префикс основной ветки диалога. Это не бесплатно и не
увеличивает лимиты провайдера. Экономия зависит от фактического переиспользования
кэша. Отключите keepalive, если у провайдера другое время жизни кэша или вам не нужны
фоновые запросы.

## Установка

Нужен Claude Code с поддержкой модулей хуков и `$.model.fork`.
В строке ввода Claude Code:

```text
/plugin install budget-guard --marketplace Hoxiee/claude-code-mods
```

Подтвердите добавление marketplace клавишей `y`, затем выберите область установки
и настройки. Или из терминала:

```sh
claude plugin install budget-guard --marketplace Hoxiee/claude-code-mods
```

Для локальной разработки:

```sh
claude --plugin-dir /path/to/neocc-mods/budget-guard
```

## Команды

| Команда | Действие |
| --- | --- |
| `/budget` | Показать лимиты, контекст, возраст кэша и счётчики keepalive |
| `/budget on` | Включить keepalive для текущей загрузки мода |
| `/budget off` | Выключить keepalive; предупреждения и защита холодного кэша продолжают работать |

Переключение командой не сохраняется как настройка. Для значения, переживающего
перезагрузку мода, используйте параметр `keepalive`.

## Настройки

| Параметр | По умолчанию | Назначение |
| --- | --- | --- |
| `keepalive` | `true` | Разрешить фоновые запросы keepalive |
| `keepaliveMinutes` | `"30"` | Горизонт простоя после последнего настоящего запроса |
| `keepaliveMinTokens` | `"30000"` | Минимальный контекст для keepalive |
| `coldCacheGuard` | `"confirm"` | `confirm`, `warn` или `off` |
| `coldCacheMinTokens` | `"60000"` | Минимальный контекст для защиты холодного кэша |
| `limitThresholds` | `"50,75,90,95"` | Пороги предупреждений о расходе 5h/7d |
| `budgetNudgeAt` | `"70"` | Порог расхода для напоминания модели; `off` отключает его |
| `contextThresholds` | `"70,85"` | Пороги заполнения окна автокомпакта |

Например, чтобы оставить предупреждения, но отключить фоновые запросы и скрытые
напоминания модели, объедините этот фрагмент с `~/.claude/settings.json`:

```json
{
  "pluginConfigs": {
    "budget-guard": { "keepalive": false, "budgetNudgeAt": "off" }
  }
}
```

## Поведение и ограничения

- Таймер проверяет состояние каждые 15 секунд. Пинг разрешён между 235-й и 285-й
  секундами после запроса, до предполагаемого истечения пятиминутного кэша.
- Keepalive пропускает выполняющиеся запросы основной ветки, маленький контекст,
  простой дольше заданного горизонта и расход подписки от 98%.
- В режиме `confirm` задержанный промпт возвращается в поле ввода. Отправьте тот же
  текст повторно в течение двух минут, чтобы продолжить. Slash-команды, программные
  и служебные промпты обходят проверку; изменённый текст требует нового подтверждения.
- Предупреждения о лимитах не дублируются после hot reload благодаря хранилищу мода.
  На порогах от 90% дополнительно запрашивается системное уведомление.
- Предупреждения о контексте предлагают `/compact` или `/clear`, но не запускают их.
- Возраст кэша и счётчики `/budget` — локальные оценки, а не гарантии провайдера.
  Hot reload сбрасывает отслеживание в памяти. Старые транскрипты мод не читает.
- Напоминание модели о высоком расходе добавляется в контекст текущего промпта,
  а не в прежнюю переписку. При `budgetNudgeAt: "off"` оно не добавляется.

## Проверка

Из корня репозитория:

```sh
claude plugin validate ./budget-guard --profile directory
claude plugin test ./budget-guard
```

В тестах часы, хранилище и fork модели подменены; настоящих запросов к модели нет.
