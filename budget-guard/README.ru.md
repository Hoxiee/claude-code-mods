# budget-guard

<img src=".claude-plugin/icon.png" alt="" width="80" height="80" align="right">

[English](README.md) | Русский

Поддержание prompt cache и предупреждения о бюджете для Claude Code. Мод следит за
запросами основной ветки диалога, лимитами подписки и размером контекста.
Команды и уведомления сейчас на русском языке.

- Поддерживает пятиминутный prompt cache во время коротких пауз.
- Позволяет отключить прогрев только в текущей сессии командой `/budget off`.
- Предупреждает о настраиваемых порогах лимитов 5h/7d и заполнения контекста.
- Просит повторный `Enter` перед запросом с большим холодным кэшем.
- Добавляет короткое напоминание модели о бюджете, когда расход высок.

**Keepalive делает настоящие фоновые запросы к модели и расходует лимиты.** Через
`$.model.fork` он перечитывает префикс основной ветки диалога. Это не бесплатно и не
увеличивает лимиты провайдера. Экономия зависит от фактического переиспользования
кэша. Отключите keepalive, если у провайдера другое время жизни кэша или вам не нужны
фоновые запросы.

## Установка

Нужен Claude Code с поддержкой модулей хуков и `$.model.fork`.
В строке ввода Claude Code:

```text
/plugin install budget-guard --marketplace Hoxiee/claude-code-mods
```

Подтвердите добавление marketplace клавишей `y`, затем выберите область установки
и настройки. Или из терминала:

```sh
claude plugin install budget-guard --marketplace Hoxiee/claude-code-mods
```

Для локальной разработки:

```sh
claude --plugin-dir /path/to/neocc-mods/budget-guard
```

## Команды

| Команда | Действие |
| --- | --- |
| `/budget` | Показать лимиты, контекст, возраст кэша и счётчики keepalive |
| `/budget on` | Включить keepalive в текущей сессии |
| `/budget off` | Выключить keepalive в текущей сессии; предупреждения и защита холодного кэша продолжают работать |

Задача закончена, а CLI остаётся открытым для чтения? Выполните `/budget off`.
Таймер автопрогрева остановится; новые пинги и повторные попытки не запускаются.
Уже начатый пинг может завершиться. Чтобы вернуть прогрев, выполните `/budget on`.
Если кэш уже остыл, мод дождётся настоящего запроса, а не станет прогревать его заново.

Переключение хранится в состоянии текущей сессии и переживает hot reload мода.
Обычные запросы не включают прогрев обратно. Другие сессии не затрагиваются;
новая сессия использует настройку `keepalive`, которую команда не изменяет.

## Настройки

| Параметр | По умолчанию | Назначение |
| --- | --- | --- |
| `keepalive` | `true` | Включать фоновые запросы keepalive по умолчанию в новых сессиях |
| `keepaliveMinutes` | `"30"` | Горизонт простоя после последнего настоящего запроса |
| `keepaliveMinTokens` | `"0"` | Минимальный контекст для keepalive; `0` отключает порог |
| `coldCacheGuard` | `"confirm"` | `confirm`, `warn` или `off` |
| `coldCacheMinTokens` | `"60000"` | Минимальный контекст для защиты холодного кэша |
| `limitThresholds` | `"50,75,90,95"` | Пороги предупреждений о расходе 5h/7d |
| `budgetNudgeAt` | `"70"` | Порог расхода для напоминания модели; `off` отключает его |
| `contextThresholds` | `"70,85"` | Пороги заполнения окна автокомпакта |

Например, чтобы оставить предупреждения, но отключить фоновые запросы и скрытые
напоминания модели, объедините этот фрагмент с `~/.claude/settings.json`:

```json
{
  "pluginConfigs": {
    "budget-guard": { "keepalive": false, "budgetNudgeAt": "off" }
  }
}
```

## Поведение и ограничения

- Таймер проверяет состояние каждые 10 секунд. При TTL `5m` автопинг отправляется
  через **4:20–4:30 от начала последнего запроса**, а не от конца ответа. Время
  генерации, в том числе самого пинга, уже расходует TTL. Если безопасное окно
  пропущено (возраст больше 285 секунд), мод ждёт нового основного запроса,
  а не оплачивает заведомо поздний прогрев.
- По умолчанию порога размера контекста нет (`keepaliveMinTokens: "0"`). При
  необходимости задайте его явно; сохранённое значение `"30000"` остаётся в силе.
- Keepalive пропускает выполняющиеся запросы основной ветки, контекст ниже
  настроенного порога, простой дольше заданного горизонта и расход подписки от 98%.
  Горизонт по умолчанию — 30 минут от последнего настоящего запроса, не от пинга.
- `/budget` показывает обратный отсчёт, причину пропуска, последний сбой и объём
  чтения, записи и вывода пингов. Временная ошибка API с нулевым расходом допускает
  повтор через 10 секунд: максимум три попытки и только до безопасного дедлайна.
  Другие ошибки или отсутствие преимущественного cache hit приостанавливают пинги
  до нового успешного основного запроса и показывают уведомление. Старый возраст
  кэша сохраняется, поэтому защита холодного кэша продолжает работать.
- `neo-statusline` начиная с 0.2.1 тоже учитывает подтверждённый cache hit фонового
  fork: отсчёт продлевается и появляется `↻`. Сам факт отправки запроса не означает
  прогрева. Обновите и перезагрузите оба установленных мода: правка исходников
  marketplace сама по себе не заменяет установленные копии.
- Пинг использует тот же префикс и настройки модели через `$.model.fork` и просит
  ответить `ok`. API fork не предоставляет `maxTokens`, поэтому это не гарантия
  нулевого вывода; короткий ответ и cache read тоже расходуют лимиты.
- В режиме `confirm` задержанный промпт возвращается в поле ввода. Отправьте тот же
  текст повторно в течение двух минут, чтобы продолжить. Slash-команды, программные
  и служебные промпты обходят проверку; изменённый текст требует нового подтверждения.
- Предупреждения о лимитах не дублируются после hot reload благодаря хранилищу мода.
  На порогах от 90% дополнительно запрашивается системное уведомление.
- Предупреждения о контексте предлагают `/compact` или `/clear`, но не запускают их.
- Возраст кэша и счётчики `/budget` — локальные оценки, а не гарантии провайдера.
  Hot reload сбрасывает возраст и счётчики, но сохраняет сессионный переключатель
  прогрева. Старые транскрипты мод не читает.
- Напоминание модели о высоком расходе добавляется в контекст текущего промпта,
  а не в прежнюю переписку. При `budgetNudgeAt: "off"` оно не добавляется.

## Проверка

Из корня репозитория:

```sh
claude plugin validate ./budget-guard --profile directory
claude plugin test ./budget-guard
```

В тестах часы, хранилище и fork модели подменены; настоящих запросов к модели нет.
