# neo-screenshots

<img src=".claude-plugin/icon.png" alt="" width="80" height="80" align="right">

[English](README.md) | Русский

Боковая панель с поиском по изображениям, прочитанным Claude Code через `Read` и
MCP-инструменты, в том числе внутри субагентов. Клик по имени файла открывает
сохранённый снимок в системном просмотрщике. Без встроенных превью, конвертации
изображений и дополнительных вызовов модели.

У каждого снимка показаны имя файла, постоянный номер, время сохранения, источник
и исходный путь, если он известен. Новые снимки появляются сверху.
Интерфейс панели сейчас на русском языке.

## Установка

Нужны Claude Code с поддержкой модулей хуков, локальная Linux-сессия с графическим
окружением, `python3` и `xdg-open` из `xdg-utils`. ImageMagick и графические протоколы
терминала не требуются.

В строке ввода Claude Code:

```text
/plugin install neo-screenshots --marketplace Hoxiee/claude-code-mods
```

Подтвердите добавление marketplace клавишей `y`, затем выберите область установки
и настройки.

Или из терминала:

```sh
claude plugin install neo-screenshots --marketplace Hoxiee/claude-code-mods
```

### Разработка из локальной копии

Запустите сессию с модом из рабочей копии репозитория:

```sh
claude --plugin-dir /path/to/neocc-mods/neo-screenshots
```

Для hot reload добавьте папку в `CLAUDE_CODE_PLUGIN_DIRS` в
`~/.claude/settings.json`. Несколько путей разделяются двоеточием (`:`) в Linux и
macOS; сохраните пути уже подключённых модов.

```json
{
  "env": { "CLAUDE_CODE_PLUGIN_DIRS": "/path/to/neocc-mods/neo-screenshots" }
}
```

## Использование

| Команда или клавиша | Действие |
| --- | --- |
| `/screenshots` | Открыть панель и перевести в неё фокус |
| `/screenshots clear` | Очистить список и поиск, не меняя исходные файлы |
| Клик по имени / `Enter` | Открыть выбранный снимок в системном просмотрщике |
| `Tab` | Перейти между полем поиска, снимками и кнопками |
| `1`–`9` | Открыть соответствующую строку текущей страницы, когда панель в фокусе, вне поля поиска |

Поиск фильтрует по имени файла, исходному пути, источнику и формату без учёта
регистра. Должны совпасть все слова запроса. «Сбросить поиск» убирает фильтр;
«Очистить список» очищает весь список и поиск.

Число строк на странице подстраивается под высоту панели, до девяти снимков.
«Новее» и «Старее» переключают страницы. Номера снимков не меняются при поиске и
перелистывании; цифровые клавиши относятся к видимым строкам, а не к этим номерам.

В полноэкранном терминальном интерфейсе панель размещается сбоку при ширине от
110 колонок. Автоматическое открытие требует 144 колонок. `/screenshots` работает
и в узком терминале, где клиент располагает панель над вводом.

## Настройки

`autoOpen` (галочка, по умолчанию включена): открывать панель после первого
сохранённого изображения, если терминал достаточно широкий. Закрытая вручную
панель не открывается повторно сама. Отключите настройку, чтобы открывать список
только командой `/screenshots`:

```json
{
  "pluginConfigs": { "neo-screenshots": { "autoOpen": false } }
}
```

Это настройка в `~/.claude/settings.json`; объедините её с существующей конфигурацией.

## Системный просмотрщик

Просмотрщик получает точные байты изображения из результата инструмента. `Read`
иногда уменьшает изображение перед передачей модели: сохраняется именно эта версия.
Перезапись исходного файла не меняет уже сохранённый снимок.

Просмотрщик запускается отдельно и не удерживает hook до закрытия окна. `xdg-open`
использует существующие ассоциации файлов рабочего окружения, не меняя их. В SSH
или headless-сессии для открытия снимка всё равно нужно графическое окружение на
машине, где работает клиент.

## Данные и ограничения

- Сбор начинается после включения мода; старая история не сканируется.
- Поддерживаются PNG, JPEG, GIF и WebP из успешных результатов `Read` и image blocks
  MCP. Изображения, вставленные напрямую в промпт, и страницы PDF не собираются.
- Повторная доставка одного результата не создаёт дубль. Новое чтение того же пути
  сохраняется отдельно, с собственным номером и временем.
- Список сохраняется при hot reload и очищается при смене сессии или `/clear`.
  Снимки из прежней версии с превью также остаются доступны, хотя их исходный путь
  может быть неизвестен; пиксельные данные старых превью удаляются из состояния.
- Снимки хранятся в отдельных приватных каталогах `neo-screenshots-*` внутри
  системного временного каталога, обычно `/tmp`, с правами 0700/0600 для каталога и
  файла. Очистка списка и завершение сессии **не удаляют** эти файлы: открытый
  просмотрщик может продолжать читать снимок. Они остаются до удаления системой
  или владельцем.
- Мод не отправляет изображения в сеть, не добавляет их в контекст модели, не
  вызывает модель повторно и не меняет исходные файлы. Максимум на один снимок —
  32 MiB.

## Проверка

Из корня репозитория:

```sh
claude plugin validate ./neo-screenshots
claude plugin test ./neo-screenshots
python3 -I ./neo-screenshots/scripts/test_image_cache.py
```

После загрузки мода клиент создаёт `.claude-plugin/types/`. Тогда доступна и
проверка типов: `tsc -p ./neo-screenshots`. Сгенерированные типы и байткод Python
исключены из git.
